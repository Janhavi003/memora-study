# Design System

Warm ivory background, near-white surfaces, charcoal typography, forest-green primary accent, muted sage, and warm-gray borders. Serif display headings and system sans UI text. Use a 4px spacing rhythm, restrained shadows, and avoid nested-card overload. Wide layouts use a sidebar; narrow layouts stack content. Keep keyboard focus visible. Dark mode uses charcoal-green surfaces and soft ivory text. Never rely on color alone to communicate status.

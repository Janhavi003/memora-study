# Design System

Warm ivory background, near-white surfaces, charcoal typography, forest-green primary accent, muted sage, and warm-gray borders. Serif display headings and system sans UI text. Use a 4px spacing rhythm, restrained shadows, and avoid nested-card overload. Wide layouts use a sidebar; narrow layouts stack content. Keep keyboard focus visible. Dark mode uses charcoal-green surfaces and soft ivory text. Never rely on color alone to communicate status.

## Memora focus palette

- Primary: Deep Indigo `#2C3E8F` for navigation, primary actions, and focus states.
- Main canvas: Soft Cream `#F7F5F0`; elevated surfaces: Warm White `#FFFFFF`.
- Text: Ink `#1F2937` and Slate `#6B7280`.
- Fresh Green `#2ECC71` signals progress and completion. Use dark text on this accent for contrast.
- Sunny Amber `#F5A623` signals streaks and rewards. Use dark text on this accent for contrast.
- Coral `#FF6B6B` is reserved for warnings and deadlines. Use dark text on coral rather than white.
- Dark mode uses charcoal surfaces and light text, with a lighter indigo for primary actions.
- Avoid relying on color alone to communicate status. Pair accents with labels or icons.
